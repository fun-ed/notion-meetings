# 前端互動與瀏覽器資產

## Markdown 與封裝（D-027）

- 摘要、筆記與留言共用 `markdown()`，以 Marked 解析 CommonMark／GFM，再經 DOMPurify 過濾。原始 HTML 先跳脫為文字；不可把 Markdown 直接當可信 HTML 插入。待辦文字用行內模式，保留原始 Markdown 與逐字稿資料。
- `ui-assets.js` 的 `loadMarkdownRuntime()` 組合本機套件程式，由公開靜態路由 `/markdown-runtime.js` 提供，不使用 CDN。路由只供應程式，不含會議或帳號資料。
- 建置產生 `.build/ui.js`：預設匯出 HTML，另以 `markdownRuntime` 匯出解析與過濾程式。執行檔必須內嵌兩者；`smoke-binary.sh` 會比對兩份資產，不能只比 HTML。

## 筆記、引用與複製

- `pendingNotes` 依會議保留待寫草稿，`notesWrites` 將自動儲存排隊。舊回應不得覆蓋後來輸入的內容；失敗保留草稿並允許導覽，不可把未寫入磁碟的內容標為已儲存。
- 摘要引用只處理一般文字節點，略過連結與程式碼。跨檔引用先切換 section 再跳時間，不可把所有檔案視為同一條音訊時間軸。
- `renderSummary()` 以顯示文字及負責人配對既有 action，使用儲存的完成狀態。同文字、同負責人的重複項目依既有順序對應；需要分開識別時才評估穩定 action ID。程式碼中的待辦範例維持程式碼顯示。
- 摘要與筆記複製渲染後的純文字，保留表格文字及勾選符號。複製用容器將 `.todo` 改為 block，避免 flex 的 `innerText` 把勾選符號拆到另一行。
- `transcriptCopy()` 沿用目前原文／精簡模式，依 section 順序輸出全域段號、各檔時間及講者；指定 section 時保留同一組全域段號。既有剪貼簿格式 `Section N：` 不隨介面中文名稱任意變動。
- 複製與狀態提示位於活動內容的工具列；單一 section 的入口在逐字稿分隔標題旁。`#copy-current`、`#copy-status` 隨目前分頁插入 DOM，應逐狀態檢查只有一組。唯讀仍可複製，權限鎖定細節見 `mem:conventions`。

## 處理入口與產品用詞

- `processingAction()` 依媒體、轉錄快取與摘要過期狀態決定唯一一般處理按鈕：待轉錄、產生摘要、更新摘要、完成後重新產生摘要。草稿不顯示空的處理入口，完成後不強調新的主要動作。
- 「全部重新轉錄」僅於已有轉錄結果時出現，會重跑既有內容；不要與重用快取的一般更新摘要混成相同操作。後端處理約束見 `mem:backend/pipeline`。
- 使用者輸入的一句話是「簡述」，LLM 全文是「摘要」，手寫內容是「我的筆記」；側欄及內容均稱「待辦事項」。空的用量列不顯示，模型產生資訊可展開查看。

## 手機導覽

- 700px 以下使用單欄主內容；側欄預設收合，展開時為 fixed 疊層，不能擠壓主內容。逐字稿時間與講者在上列，內容另佔整列。
- `narrowScreen` 的斷點事件套用對應狀態。手機開關不寫入桌面的 `sideCollapsed` 偏好，返回桌面時恢復原偏好。
- 手機選擇導覽連結或按 Escape 會收起。展開時聚焦第一個可見連結，略過唯讀帳號隱藏的新增會議；收起後焦點回開啟按鈕。匿名頁不顯示側欄開啟按鈕。
